## Descripción

**OSCAROMARGP** es una landing page premium diseñada para mostrar los servicios de diseño gráfico, branding y editorial de Oscar Omar Gómez Peña.

### Propuesta de Valor Completa

| Aspecto | Descripción |
|---------|-------------|
| **Nombre** | OSCAROMARGP - Diseño Gráfico, Branding y Editorial |
| **Sector** | Diseño gráfico, marketing digital, desarrollo web |
| **Trayectoria** | Desde 2015 (11+ años de experiencia) |
| **Especialidad** | Diseño editorial, branding, medios impresos, publicaciones gubernamentales |
| **Acreditaciones** | Diseñador Acreditado en Diario de Acayucan, Informes de Gobierno Municipal |
| **Tagline** | "Tu imagen es mi artesanía" |
| **Color Principal** | Púrpura (#A855F7) |
| **Ubicación** | Acayucan, Veracruz, México |
| **Operación** | Remota global |

### Problema que Resuelve

En un mercado saturado de diseñadores genéricos, Oscar destaca por:
- Trayectoria comprobable en medios impresos y publicaciones gubernamentales
- Experiencia real con créditos oficiales en Diario de Acayucan
- Diseño de informes de gobierno municipal con calidad profesional
- Presencia digital completa en 7+ plataformas

### Beneficios Clave

- ✅ **Trayectoria Verificable** - Créditos oficiales en Diario de Acayucan (desde 2013)
- ✅ **Experiencia Gubernamental** - Informes de gobierno municipal publicados
- ✅ **Presencia Digital Completa** - 7 plataformas actualizadas activamente
- ✅ **Versatilidad** - Diseño, desarrollo, automatización y marketing
- ✅ **Cierre Rápido** - 3 formularios de contacto + WhatsApp directo

## Deployment

### GitHub Pages (Recomendado)

1. **Fork o clone** el repositorio
2. Ve a **Settings** > **Pages**
3. En "Source", selecciona **main** branch
4. Click en **Save**
5. Espera 2-3 minutos
6. Tu sitio estará en: `https://oscaromargp.github.io/Oscaromargp/`

### Vercel


1. Ir a [netlify.com](https://netlify.com)

## Personalización

### Guía para Colores

#### Cambiar Color Principal

1. Abrir `styles.css`
2. Buscar `:root` (~línea 7)
3. Modificar `--primary-400` al color deseado

```css
:root {
    /* Original */
    --primary-400: #A855F7;
    
    /* Alternativas populares */
    /* Azul: #3B82F6 */
    /* Verde: #22C55E */
    /* Naranja: #F97316 */
    /* Rosa: #EC4899 */
}
```
